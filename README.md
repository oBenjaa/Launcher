### Launcher em C# para rodar em seu navegador

Este foi um projeto criado para rodar um Launcher em C# no seu navegador na porta 5000.

- **Como utilizar**
- **Clone o repositório:**
 ``git clone git@github.com:oBenjaa/Launcher.git``
- **Tenha instalado a versão do [Dotnet](https://dotnet.microsoft.com/pt-br/download/dotnet/thank-you/sdk-8.0.416-windows-x64-installer) 7 ou superior em sua máquina.**
